# Design

Campus Customs now uses an original heritage-retail direction informed by J. Press: classic Yale/New Haven references, quiet editorial layouts, and the clarity of a collegiate outfitter. It does not copy J. Press branding, text, assets, or source code.

- **Color:** Yale Blue, deep ink navy, warm ivory, paper white, and restrained oxblood create a recognizable collegiate system. Muted gold and forest accents remain available for small heritage details, not large surfaces.
- **Typography:** Editorial serif headlines create a magazine/catalogue voice, while a clean sans-serif handles navigation, product names, prices, filters, forms, and chat for fast scanning.
- **Header and wordmark:** A thin New Haven announcement bar, centered Campus Customs lockup, left navigation, right utility actions, thin rules, and a responsive menu create an understated outfitter header.
- **Homepage:** The product-led hero, real catalogue favourites, catalogue-driven category tiles, New Haven editorial band, campus-classic CTA, and story sequence give the store a considered retail rhythm.
- **Product presentation:** Real product images dominate minimal cards with subtle image scale and arrow feedback. Detail pages keep a large image, actual price/colors/description, rectangular sizes, and live stock states visible.
- **Catalogue controls:** Search, garment type, color, price, sorting, active filter chips, tailored result headings, and recently viewed remain instant and easy to interpret.
- **Account, bag, and chat:** The linked account dashboard, local bag drawer, and Campus Concierge share the same ivory/navy system, so utility features feel like part of the store rather than a separate app.
- **Motion and responsive behavior:** Short fades, restrained hover states, drawer transitions, keyboard focus styles, touch-friendly controls, stacked mobile layouts, and reduced-motion support preserve usability.
- **Original details:** CSS line rules, corner marks, catalogue numbering, New Haven references, and small arrows provide archival-catalogue character without using third-party graphics.

These decisions make the merchandise easier to browse, give the Yale store a more confident point of view, and preserve the existing database, authentication, cart, memory, and agent functionality underneath the redesign.
